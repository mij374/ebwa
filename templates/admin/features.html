Copies each archive to the NAS over SFTP, across Tailscale. This is what makes the backups real: until a copy is on another machine, a lost server is lost data.

{% endif %}
The Tailscale name or address. Tailscale must be running on this server and on the NAS.

UTC, not British time — 02:30 UTC is 03:30 in the summer. A cron job on the server checks every fifteen minutes and runs it once the time has passed.
