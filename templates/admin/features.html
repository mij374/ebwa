How to change the SMTP password
  1. Connect to the server over SSH.
  2. Open the environment file: 
    sudo nano {{ deploy.env_file }}
  3. Edit or add the line below. No spaces around the equals sign, and single quotes around the value — the quotes protect $, #, ! and spaces: 
    SMTP_PASSWORD='new-password-here'
  4. Save and exit: Ctrl+O, Enter, Ctrl+X.
  5. Check the file still parses. One malformed line stops the service reading any of its settings, so this step is worth the ten seconds: 
    sudo -u {{ deploy.user }} bash -c 'set -a; source {{ deploy.env_file }}; set +a; echo "env OK"'
  6. Restart the service so it picks up the change: 
    sudo systemctl restart {{ deploy.service }}
  7. Confirm it works — put your own address in: 
    sudo -u {{ deploy.user }} bash -c 'cd {{ deploy.path }} && set -a && source {{ deploy.env_file }} && set +a && ./venv/bin/flask --app app test-mail your@address.com'
    Or use Send a test email below, once the service has restarted.

Leave the file's permissions as root:{{ deploy.user }} and 640 — readable by the service, by nobody else:

sudo chown root:{{ deploy.user }} {{ deploy.env_file }}
sudo chmod 640 {{ deploy.env_file }}

An archive on this server is not a backup. It protects against a mistake — a deleted album, a bad edit — not against losing the server. Copying archives off the machine to a NAS or another host is a scheduled job on the server (cron with rsync or scp and a key), set up by Netbus. This page cannot configure that, and deliberately does not try: the website has no business holding keys to other machines or running commands anybody typed into it.
