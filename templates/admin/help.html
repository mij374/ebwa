1. Signing in

The admin lives at /admin — so if the website is ebwa.org.uk, the address is ebwa.org.uk/admin. Sign in with the email address and password Netbus set up for you.

{{ shot("sign-in", "The sign-in page: a white card headed EBWA Admin with an Email address box, a Password box and a green Sign in button.", "The sign-in page. If you have two-factor sign-in switched on, a second screen asks for the six-digit code from your phone after this one.") }}
  • You are signed out after 20 minutes of doing nothing. That is deliberate — an admin left open on a shared computer is an admin anyone can use. If it happens, the page says so and you simply sign in again.
  • There is no “forgotten password” link. A reset link sent by email is another way in for somebody who should not have one, so instead you ring Netbus and they reset it on the server.
  • You can change your own password at any time — see Your account.

2. The dashboard, and “needs attention”

The first page after signing in is the dashboard. It answers one question: is there anything waiting for me today?

{{ shot("dashboard-attention", "The Needs attention panel. A red heading reads LAUNCH BLOCKER — the privacy notice and terms are still the placeholder wording, with a Write them link. Below it, one line each for enquiries nobody has read, a membership application waiting, events now past, and published items with no photo — each with a link on the right.", "“Needs attention” only appears when there is something in it. An empty panel is not shown at all, so if you cannot see this box there is nothing outstanding.") }}

Each line is one sentence and a link straight to where the fix happens. The things it watches for are:

  • Enquiries nobody has read — somebody used the contact form and is waiting for a reply.
  • Membership applications waiting — shown as the one red card, because a person is waiting on a decision.
  • Events now past — still published, so still on the site under “Past events”. That is often right; the line is a reminder, not a telling-off.
  • Published items with no photo — a page with no picture looks unfinished.
  • Placeholder text — wording that came with the site and was never replaced. The privacy notice and terms are flagged as a launch blocker: they are a legal requirement, and EBWA has to supply the real text.
{{ shot("dashboard-cards", "Rows of dashboard cards grouped under headings, each showing a figure — events, news posts, gallery photographs, testimonials and so on — with the number of unpublished items noted underneath, and each card linking to its own admin page.", "Below the attention panel, a card for every part of the site. The small grey line under a figure tells you how many are not published yet.") }}

The dashboard only ever shows totals. It never shows a person's name, address or the amount they gave — for that you go to the page that holds it, and the site records that you looked.

3. Four things worth knowing first

These four come up on nearly every screen, so they are worth reading once rather than discovering one at a time.

Published means “on the website”

Almost everything you can add has a Published tick-box. Ticked, it is on the public site. Unticked, it is saved here and nobody outside can see it — which is how you write something now and put it up later.

{{ shot("event-form-published", "A single form row: a tick-box, ticked, labelled Published (visible on the website).", "The Published tick-box, at the bottom of every form that has one. If it is ticked when you open the form, that item is currently live — leave it ticked unless you mean to take it down.") }}

Sort order: lowest number first

Lists that you arrange yourself have a Sort order box. Lower numbers come first. Leaving them all at 0 is fine — things then fall back to newest first — and you only need to touch it when you want something pinned to the top.

{{ shot("sort-field", "A form row labelled Sort order with a number box containing 0, and a note underneath explaining that lower numbers appear first and a negative number pins an item to the top.", "Sort order. A negative number, like -1, pins something above everything else — useful for one item you want first without renumbering the rest.") }}

Delete really does delete

Every delete asks you to confirm, and then it is gone. There is no undo and no wastebasket. If you are not sure, untick Published instead — that takes it off the website and keeps it here.

One thing is deliberately safe: deleting a photo album does not delete the photographs. They move to “All photos” and you can put them in another album. An album is an arrangement; a photograph of somebody's grandmother is not.

Photographs are made smaller and stripped of location data

When you upload a photo the site shrinks it, so pages load quickly on a phone, and removes the hidden information the camera put in it — including where it was taken. Photos taken on a phone usually carry GPS coordinates, often somebody's home, and the site publishes the picture and not that. You do not have to do anything; it is automatic.

Every photo asks for a short description. That is what a blind visitor's screen reader reads out, and it is what shows if the picture fails to load. Describe what is in it — “Children at the Saturday Bengali class”, not “photo1”.

4. Events

Events in the sidebar lists everything, soonest first. The site sorts events into “Upcoming” and “Past” by their date on its own — you never have to move one.

{{ shot("events-list", "The events list as a table with columns for date, title, venue and status, each row ending in Edit and Delete links, and a green Add event button above the table.", "The events list. The status column tells you at a glance whether each one is on the website.") }}

To add one, press Add event and fill in the form.

{{ shot("event-form-top", "The top of the event form, showing boxes for Title, Date, Start time, Venue, a short Summary and a longer Description, followed by a button to choose a photograph.", "The top half of the event form. Only the title and date are required; everything else can be added later.") }}
  • Date is a real date, so the site knows when the event has passed.
  • Start time is just words — “6:30 pm”, “after Maghrib”, “doors 6.45”. It prints exactly as you type it, so write what you would say.
  • Summary is the line that appears on the card in listings. Keep it to a sentence.
  • Description is the full page. Leave a blank line between paragraphs and they come out as paragraphs.
  • Photo is the picture used on the card and at the top of the page.

Save it, and it is on the website straight away — assuming Published is ticked.

5. Photos, layout and video on a page

Once an event or news post has been saved, more options appear underneath the form: how the page is arranged, a video, and as many extra photographs as you like. These work the same way on events, news posts, Our Journey entries and the About page.

{{ shot("event-form-photos", "A section headed Page layout with a drop-down currently reading Classic — a lead photo beside the text, the rest in a strip underneath — and a Save layout button. Below it a section headed Video explaining that a video is only contacted when a visitor presses play.", "Page layout and Video, below the main form. Choose a layout, save, then look at the public page — you can change it back at any time.") }}

There are three layouts, and the quickest way to choose is to try one and look at the page:

  • Classic — one lead photo beside the words, any others in a strip underneath.
  • Gallery — the words, then all the photographs together in a grid.
  • Alternating — photo, words, photo, words down the page, side to side.

Gallery and Alternating need photographs to show their shape. With none, the page falls back to Classic on its own.

{{ shot("event-form-photo-list", "A section headed Photos with a file chooser, a box for a short description of the picture, a sort-order box, and beneath them the photographs already added, each with its own caption and description boxes and a Remove link.", "The photo manager. Add photographs one at a time; the short description is required, because a picture nobody can describe is one a blind visitor simply loses.") }}

For video, paste the ordinary link to a YouTube or Vimeo page — the one in the address bar. You do not need any embed code, and if you paste one the site quietly takes just the video out of it.

The page shows a still picture with a play button, and only contacts YouTube if a visitor actually presses play. That is why the site can honestly say it does not track anybody. You can also choose where the video sits: at the top, after the words, or at the very end.

6. News & Projects

News works exactly like events, minus the date and venue. The three most recent published posts appear on the homepage.

{{ shot("news-form", "The news post form, with boxes for Title, a short Summary, the main Body text, and a photograph chooser.", "The news form. As with events, layout, video and extra photos appear underneath once the post has been saved once.") }}

Use news for things that happened or are happening — a grant awarded, a term starting, a trip report. Use events for something with a date people can come to.

7. The gallery and its albums

The gallery has two screens: the photographs, and the albums they are arranged into.

{{ shot("gallery-albums", "The albums list as a table: three albums named Eid at the centre, Summer day out 2026 and Weekend school, each showing how many photographs it holds, with Edit and Delete links.", "Albums. The count beside each is how many photographs are filed in it.") }} {{ shot("gallery-photos", "A grid of photograph thumbnails, each with a tick-box in the corner for selecting it, and a drop-down above for moving the selected photographs into an album.", "The photographs themselves. Tick several and use the drop-down above to move them into an album in one go.") }}

Things worth knowing:

  • A photograph does not have to be in an album. Anything unfiled still appears under “All photos” on the website, so nothing is ever lost or unreachable.
  • Deleting an album never deletes photographs — they go back to being unfiled.
  • Hiding an album hides its photographs everywhere, including “All photos”. You will still see them here.
  • Portrait photos stay portrait. The gallery uses each picture's real shape rather than cropping everything into squares.

8. Page content — the words on the site

Page content is where the fixed wording lives: the homepage headings, the About text, the address and phone number in the footer, the words on the contact page. Anything a visitor reads that is not an event, a news post or a photograph is probably here.

{{ shot("page-content-tabs", "A row of tabs across the top of the page content screen — Home, About, Contact, Site, Journey, Legal — with one highlighted as the current tab.", "The tabs group the wording by where it appears. Pick a tab, change the boxes, press Save.") }}

Each box is one piece of text on the site, with its own label. Change it, save, and refresh the public page to see it.

Two of these matter more than the rest: Legal holds the privacy notice and the terms, and both ship with placeholder wording that EBWA must replace before the site goes live. The dashboard nags about it for exactly that reason.

9. Testimonials

Short quotes from members, shown in a moving row on the homepage. Add the person's name, what they are (“Member”, “Volunteer”), and what they said.

{{ shot("testimonials-notice", "A Needs attention box on the testimonials page reading: you have 14 published testimonials, the homepage shows the first 12, and the other 2 are published but not visible anywhere. It goes on to explain that the sort order decides which appear.", "This notice appears once you have more than twelve published quotes. It is the one place where “published” does not mean “somebody can see it”.") }}

The homepage shows the first twelve. There is no page listing all the testimonials, so a thirteenth quote is published but not actually anywhere. To bring one onto the homepage, give it a lower sort number than the ones already showing.

A testimonial is somebody else's words, so edit rather than retype. Fixing a typo by deleting and re-adding means typing their quote from memory.

10. Collections and donations

A collection is money raised for one specific thing — a coach trip, an appeal — with its own page, a running total and an optional target. A donation is a plain gift to EBWA through /donate.

{{ shot("collection-form", "The collection form, with boxes for the title, a description, the fee per place in pounds, a fundraising target, and a photograph.", "The collection form. The fee is what one place costs; leave it empty for an appeal that is donations only.") }}

The most important control here is what the collection is doing, because it separates two different questions: is this page on the website, and is it taking money?

{{ shot("collection-state", "A drop-down labelled What this collection is doing, set to Taking payments, with the three choices explained underneath: Taking payments — on the website with the payment form; Closed — still on the website, shown with its final total and a line saying it has finished, nobody can pay; Hidden — off the public website entirely, with contributor lists and Gift Aid records still available in the admin.", "The three states. When a trip has happened, set it to Closed — not Hidden — so the record of it stays on the site with its final total.") }}
  • Taking payments — the normal state.
  • Closed — the trip has happened. The page stays up with its final total and a line saying it has finished. Nobody can pay, and that is enforced properly, not just by hiding the form.
  • Hidden — off the public site altogether. Use it for something you are still writing.

Whichever state it is in, the contributor list, the CSV export and the Gift Aid records stay available here — the treasurer needs them most once a collection has finished.

Gift Aid — the rule that must not be bent

Gift Aid can only be claimed on a genuine gift. A payment for a place on a trip is not a gift: the person gets a seat on a coach for it. So on a collection page the money is split in two — the fee for the place, which can never carry Gift Aid, and an optional extra donation on top, which can.

You do not have to police this. The site will not let Gift Aid be attached to a fee, and the Gift Aid page exports only the donation parts that carry a valid declaration, in the layout HMRC asks for. But it is worth understanding, because somebody will ask.

11. Enquiries and members

Enquiries holds messages sent through the contact form. The sidebar shows a badge with how many nobody has read.

{{ shot("enquiries-list", "The enquiries list as a table with columns for when it was received, who from with their email address, the subject and message, a status pill reading New, and links to reply, mark as read and delete.", "Enquiries. Reply opens your normal email program with the address filled in — replies do not go out from the website.") }}

These are real people's names, addresses and questions, so:

  • They are admin-only and never appear anywhere public.
  • There is no export. There is no good reason to bulk-download somebody's question about a lunch club.
  • Opening the list is recorded in the audit log, as is deleting one. That is normal and expected — it is a record of who looked at people's personal information, which is what the law expects a charity to be able to show.

Membership works the same way, with a status you move along: new → contacted → approved or declined. One field there is special-category data under data protection law — the question about Bangladeshi origin, which is a question about ethnicity. Treat that screen accordingly: do not copy it into a spreadsheet, and do not email it around.

12. Visitors — how many people read the site

Visitors shows how many people are reading the website. The figures are counted on EBWA's own server: there is no Google Analytics, no third-party service and no extra cookie, and nothing is stored that identifies anybody.

{{ shot("visitors-figures", "Four figures side by side — today, this week, this month, and the same month last year — each with the number of page views above and a short label below.", "The headline figures. “This month last year” fills in once the site has been running a year.") }} {{ shot("visitors-chart", "A bar chart of page views for the last thirty days, one bar per day, with the most recent day picked out, and the dates labelled along the bottom.", "The last thirty days. The chart is drawn by the site itself, so no data about your visitors leaves the server.") }}

What a “visit” means, because the number gets quoted: one person on one day. Somebody who comes back next week is counted again. So a month's figure is not a count of different people — it is closer to “person-days”. Only the “today” figure is people.

Report for a period produces a printable document with the figures, the comparison with last year and EBWA's charity number on it — meant for grant applications. Use your browser's Print and save it as a PDF.

13. Your account and password

Account in the sidebar is where you change your own password. You need your current one to set a new one.

It is also where you can switch on two-factor sign-in: after your password, the site asks for a six-digit code from an app on your phone. It is worth doing. You are shown a set of recovery codes once when you set it up — print them or write them down, because if you lose the phone they are the way back in, and they cannot be shown again.

14. What Netbus looks after

A few screens are Netbus's rather than EBWA's, and are only visible to them. They are listed here so you know what exists and what to ask for.

{{ shot("help-sidebar", "The admin sidebar, listing Dashboard, Page content, What we do, Events, News and Projects, Gallery, Testimonials, Partners, FAQ, Resources, Our Journey, Enquiries, Subscribers, Membership, Collections, Gift Aid, Account, Help and Visitors.", "The sidebar. What you see depends on which parts of the site are switched on and whether you are an EBWA admin or Netbus.") }}
  • Settings — switching whole sections of the site on and off, the email settings, the backups, and the order of the homepage.
  • Users — adding and removing admin accounts.
  • Audit log — a record of everything anybody changed. It can never be edited or switched off, which is what makes it worth having.
  • Backups — taken automatically every night and copied to a second machine. Nobody at EBWA needs to do anything.

15. If something looks wrong

I changed something and the website looks the same
Refresh the public page — your browser may be showing you the copy it already had. If it is still wrong, check the item is Published.
A whole section has vanished from the website
Most sections can be switched off in Settings. Nothing is deleted when that happens and switching it back on restores it exactly. Ask Netbus.
A photograph shows as a broken box
The picture file is missing from the server, usually after a restore. Signed in, you see a note naming the missing file; a visitor sees the page close up neatly around it. Upload the photo again, or tell Netbus.
I deleted something by mistake
Ring Netbus the same day. There is a backup from every night, so it can usually be recovered — but the sooner the better.
Somebody's testimonial is not on the homepage
You probably have more than twelve published. See Testimonials.
An event has finished but is still on the site
That is normal — it moves to “Past events” on its own. Untick Published to take it off entirely.

Anything not covered here, or anything that looks broken rather than confusing: Netbus IT Support.
