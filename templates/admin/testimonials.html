How the row moves

This applies to the whole row, not to one quote. With {{ scroller_min }} or more testimonials the row becomes a scroller; with fewer it is a plain grid and sits still whatever is chosen here.

These are separate from the partner row's settings, so the quotes can stand still while the logos drift. A quote is something a visitor has to READ, and moving text is harder to read than a moving logo — which is why this row starts still.

Speed settings

These change how the testimonial row looks and feels on the website. The defaults have been tested across screen sizes and devices; only change them if you are sure. You can put them back at any time with Reset to defaults below.

Milliseconds the row spends sliding from one quote to the next — the movement itself, not the wait in between. Between {{ glide_min }} and {{ glide_max }}. Default: {{ motion.glide_default }}ms. It cannot be longer than the wait between steps, or the row would start moving again before it had finished.
Pixels a second, for “Continuous smooth scroll”. The default of {{ motion.drift_default }} moves about one quote card every eight seconds. Between {{ drift_min }} and {{ drift_max }}. Default: {{ motion.drift_default }} pixels a second. A speed rather than a lap time on purpose: a lap gets longer every time you add a quote, so the same lap time would mean a different speed on every site.

Visitors whose device has reduced motion turned on will always see a still row with arrow buttons, whichever option is chosen here — that setting is theirs to make, and this page does not override it. Neither speed above applies to them.
