{# Browser-tab and home-screen icons, plus the mobile browser chrome colour. Included by EVERY template that owns a — the public base, the admin base and both login pages — so the set cannot drift apart again. Add an icon here, never in one template. The icons are the simplified lily mark (ebwa-mark.png), not the full badge (ebwa-logo.png): the badge's lettering and Bengali script turn to mush below about 64px. See CLAUDE.md if they ever need regenerating. Every href here carries asset_version(), as the stylesheet does in each of the four templates that include this one: nginx serves /static/ with `expires 30d`, so a URL that does not change when the file does is a month of the old file.
